# PopX Auth UI 🚀

A clean and responsive authentication UI built using React.js and Tailwind CSS.  
This project includes modern mobile-style screens for user onboarding and authentication.

## ✨ Features

- Welcome Screen
- Sign Up Screen (Form + Radio Buttons)
- Sign In Screen
- Bottom-aligned mobile UI layout
- Responsive design (mobile-first)
- Clean and minimal UI
